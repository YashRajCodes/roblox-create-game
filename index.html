faq

how do I make a game pass on roblox mobile?

the roblox app can't create games, and every game pass has to belong to a game. run the code above to make a game first. it opens the game's passes page, where you create a pass, give it a name and image, then turn on "item for sale" and set a price in robux.

why do I need a game to make a game pass?

game passes are sold inside a game, so roblox only lets you create them for a game you own. donation games like pls donate also read passes from your public games, so the game has to be public too.

what does the script do?

it creates a new game on your account from the ugc homestore template, names it "[your username]'s donation game", answers the maturity questionnaire with "no" for every question, makes the game public, and opens its game passes page.

is it safe?

the script runs in your browser on roblox.com using the account you're already logged into. it doesn't ask for your password and doesn't send anything anywhere except roblox's own servers. the full source is on github. as a general rule, only run javascript: code from sources you trust, since it can do anything your account can.

does it work on iphone and android?

yes. the phone steps are written for chrome. if typing javascript: in the address bar doesn't show a link in your browser, bookmark any page, edit the bookmark, replace its address with the code, then open roblox.com and tap the bookmark.

why does it have to run on www.roblox.com?

the script uses your login on www.roblox.com. create.roblox.com has a content security policy that blocks bookmarklets, so running it there does nothing.

does it cost robux?

no. making a game is free, and so is this tool. when someone buys one of your game passes, roblox keeps 30% and you get 70% of the price.

can I rename the game or make more than one?

yes. you can change the name, icon, and description from the creator dashboard at any time. running the script again makes another new game.

it showed an error. what now?

the error says which step failed. check that you're logged in and on www.roblox.com, then try again. if a game was already made before the error, you can find it in the creator dashboard under creations.
