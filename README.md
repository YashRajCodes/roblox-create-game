# make a roblox game on mobile (no roblox studio)

a bookmarklet that creates a public roblox game from your phone, so you can make game passes without roblox studio or a computer.

it creates a game from a template, fills in the maturity questionnaire, makes the game public, and opens its game passes page.

## usage

go to [yashrajcodes.github.io/roblox-create-game](https://yashrajcodes.github.io/roblox-create-game/) to get the code.

### on desktop

1. drag the "drag to bookmarks" button to your bookmarks bar.
2. open [roblox.com](https://www.roblox.com) and log in.
3. click the bookmark. your game gets made and you land on its game passes page.

### on phone

1. tap the code box to copy it.
2. open [roblox.com](https://www.roblox.com) and log in.
3. tap the address bar, type `javascript:` and paste the code right after it. (pasting removes the `javascript:` part, so you have to type it.)
4. don't press enter. tap the blue link that shows up under the address bar.
5. your game gets made and you land on its game passes page.

note: it has to run on www.roblox.com. it won't work on create.roblox.com because that site's content security policy blocks bookmarklets.
